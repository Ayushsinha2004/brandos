# General Transcript to LinkedIn Post Repurposing

> **Purpose**: Transform any transcript (YouTube, Sales Call, Meeting, etc.) into high-performing LinkedIn posts in Govind's brand voice.

---

## Goal

Take a transcript as input and repurpose it into a LinkedIn post that:
- Maintains Govind's authentic brand voice
- Follows proven LinkedIn post structures
- Simplifies complex AI/automation concepts for non-technical founders
- Drives engagement and conversions

---

## Process Flow

### Step 1: Extract Core Value

From the transcript, identify:
- **Main insight/framework** being taught or discussed
- **Key pain points** addressed
- **Transformation/outcome** promised
- **Proof points** or results mentioned
- **Unique mechanism** or approach

### Step 2: Apply Brand Voice

Using `v1-brand_voice.json`, ensure the post:
- Uses Govind's vocabulary patterns
- Matches his sentence rhythm and pacing
- Reflects his direct, no-BS communication style
- Maintains technical credibility while being accessible

### Step 3: Structure with LinkedIn Patterns

Follow the proven structure from `example_linkedIn.md`:

```
[HOOK - 2 lines max, stops the scroll]
(Parenthetical that creates intrigue)

[PROBLEM - Why most people fail at this]

---

𝗧𝗵𝗲 𝘀𝗼𝗹𝘂𝘁𝗶𝗼𝗻: [Bold header]

[Core framework/insight from the source]

---

𝗛𝗼𝘄 𝗶𝘁 𝘄𝗼𝗿𝗸𝘀:

→ Step/Layer 1
→ Step/Layer 2
→ Step/Layer 3

---

𝗧𝗵𝗲 𝗿𝗲𝘀𝘂𝗹𝘁𝘀:

[Proof points with specific numbers]

---

[CTA - comment trigger, DM request, or link]

[Closing hook - "95% will..." pattern]

♻️ Repost to help someone [benefit].

[Media indicator: Video/Image/Carousel]
```

### Step 4: Format for LinkedIn

- **Short sentences**: 10-12 words max
- **White space**: Single line between thoughts
- **Visual markers**: →, ✓, ❌, 1️⃣, 2️⃣, 3️⃣
- **Bold headers**: Use 𝗯𝗼𝗹𝗱 unicode for section breaks
- **Horizontal dividers**: --- between major sections

### Step 5: Optimize for Engagement

**Hook formula**: 
- Specific number/result + impossible claim
- Example: "This FREE AI system builds skills 10x faster than courses or coaching."

**Re-hook formula**:
- Parenthetical that deepens intrigue
- Example: "(And you can build it in 10 minutes)"

**CTA patterns**:
- Engagement: "Comment [KEYWORD] below"
- Connection: "1️⃣ Connect with me 2️⃣ Like + Comment"
- Scarcity: "Closing in 48 hours"

## Saving Generated Posts

**All generated LinkedIn posts must be saved locally** to maintain a content archive and enable version control.

### File Location
Save all posts to: `directives/content/linkedincontent/posts/`

### Naming Schema
Use sequential numbering starting from 1:
- Format: `{number}.{descriptive-title}.md`
- Examples:
  - `1.ai-skill-building-system.md`
  - `2.sales-call-training-framework.md`
  - `3.automation-roi-breakdown.md`

### Numbering Rules
1. **Check existing files** in the `posts/` folder before creating a new post
2. **Find the highest number** currently used (e.g., if `5.example.md` exists, the highest is 5)
3. **Increment by 1** for the new post (next would be `6.new-post.md`)
4. **Use descriptive titles** in kebab-case (lowercase with hyphens)
5. **Keep titles concise** - 3-5 words maximum

### File Content Structure
Each saved post file should contain:

```markdown
# [Post Title]

**Source**: [YouTube URL / Meeting / Sales Call / etc.]
**Created**: [Date]
**Status**: [Drafting / Review / Published]

---

## Hook
[First 2 lines of the post]

---

## Full Post

[Complete LinkedIn post content]

---

## Metadata
- **Content Type**: Text / Carousel / Image / Document
- **CTA Type**: Comment Below / DM Me / Like/Share / Visit Website
- **Target Audience**: [Specific ICP segment if applicable]
- **Key Topics**: [Tags/keywords]
```

### Execution Tool
Use `execution/content/save_linkedin_post.py` to handle file creation with proper numbering.

## Edge Cases

| Scenario | Handling |
|----------|----------|
| Transcript too long | Focus on ONE core insight, save others for future posts |
| No clear framework | Extract the underlying principle and structure it |
| Too technical | Simplify using analogies and real-world examples |
| No results mentioned | Use hypothetical outcomes or focus on mechanism |
| Multiple topics | Pick the most LinkedIn-friendly angle (controversy, transformation, framework) |
